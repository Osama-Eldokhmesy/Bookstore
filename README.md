# Bookstore

This project is a simple and responsive front-end interface for managing and displaying books. The layout includes search functionality, category filters, book cards, CRUD modals, and a rating system. It is suitable as a small web admin dashboard or a front-facing catalog.

---

## Features

### Search and Filtering
- Search bar for filtering books by title.
- Category filter buttons with an active state.

### Book Grid Layout
- Responsive grid system built with CSS Grid.
- Each book card includes:
  - Cover image
  - Edit action
  - Delete action
  - Hover animation for better user experience.

### Modal Forms
- Add and edit book details through modal popups.
- Form fields include title, description, category, and image URL.

### Rating System
- Clickable star-based rating interface.
- Stars highlight when selected.

### Responsive Design
- Layout adjusts to desktop, tablet, and mobile screens without breaking.
